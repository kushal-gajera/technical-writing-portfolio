# Beamer

Beamer is a LaTeX document class used to create slide presentations. A presentation is divided into frames, and each frame can contain text, lists, images, tables, columns or blocks.

## Topics covered

- Creating a title page and frames.
- Adding sections and slide titles.
- Dividing a slide into columns.
- Using block, alertblock and exampleblock.
- Adding bullet points, tables and equations.
- Selecting a theme and colour theme.

## Compile

```bash
pdflatex presentation.tex
pdflatex presentation.tex
```

Open `presentation.tex` in Overleaf or a desktop LaTeX editor to customise the author, institute and slide content.

## Practical activity

Add a new frame with two columns. Place a definition inside a block in the first column and an example in the second column. Compile the presentation and check that all content fits.
