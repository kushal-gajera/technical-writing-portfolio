# Google Docs

Google Docs is a web-based word processor for creating, formatting, sharing and collaboratively reviewing documents.

## Create a document

1. Visit [Google Docs](https://docs.google.com/).
2. Choose a blank document or a template.
3. Give it a clear title.
4. Organise the content into sections.
5. Apply paragraph styles to headings instead of formatting every heading manually.

## Formatting and page layout

| Feature | Where it helps |
|---|---|
| Paragraph styles | Consistent title and heading hierarchy |
| Font and size | Readable typography |
| Alignment and spacing | Clear paragraphs |
| Margins and paper size | Control the page layout |
| Headers and footers | Repeat document information |
| Page numbers | Navigate longer reports |
| Columns | Arrange selected content in columns |
| Bullets and numbering | Present lists and procedures |
| Tables and images | Explain structured information visually |

## Collaboration

- **Comments:** ask a question about selected text.
- **Suggesting mode:** propose an edit without directly replacing the original.
- **Sharing:** choose Viewer, Commenter or Editor access.
- **Version history:** inspect or restore an earlier version.

## Export

Use **File → Download** to export a PDF or DOCX file. Check page breaks, links, images, tables and page numbers after export.

## Practical activity

Create a two-page report containing headings, a numbered procedure, one table, an image with a caption, a hyperlink and page numbers.
