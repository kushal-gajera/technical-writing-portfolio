# Contributing to this learning portfolio

This is an educational repository. Improve clarity, correctness and reproducibility.

Before submission:
1. Replace sample student details with your own.
2. Run the examples and add screenshots of your own results.
3. Complete the learning journal honestly.
4. Never commit passwords, access tokens or private information.

Suggested workflow:

```bash
git switch -c docs/improve-a-guide
git status
git diff
git add docs/
git commit -m "docs: improve technical writing guide"
git push -u origin docs/improve-a-guide
```

Use focused commits and review changes before opening a pull request.
