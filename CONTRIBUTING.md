# Contributing

This repository is a student learning portfolio for the Technical Writing course.

## Before making a change

- Read the README in the topic folder.
- Keep examples small and easy to reproduce.
- Use clear filenames and meaningful headings.
- Keep source files alongside their explanations.

## Writing and examples

- Explain the purpose before showing commands.
- Include prerequisites and expected results.
- Use consistent terminology and formatting.
- Check links and compile examples where possible.
- Do not add generated build output unless it is needed to understand the example.

## Commit messages

Use short messages that describe the change, such as:

- `Add page layout example`
- `Explain Doxygen comment tags`
- `Update Google Docs formatting guide`

Avoid artificial commits or messages that do not describe the actual work.
