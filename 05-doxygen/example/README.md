# Doxygen C++ Example

This folder contains a small C++ source file and the Doxygen configuration.

## Files

- `main.cpp` — functions documented with Doxygen-style comments.
- `Doxyfile` — settings that tell Doxygen what to scan and generate.

## Generate documentation

1. Install Doxygen.
2. Open a terminal in this folder.
3. Run `doxygen Doxyfile`.
4. Open the generated `html/index.html` page in a browser.

Edit the comments in `main.cpp` and regenerate the output to see how the documentation changes.
