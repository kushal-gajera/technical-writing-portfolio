# Formatting and Page Layout in Google Docs

A consistent layout makes a report easier to read. Use paragraph styles and page settings so that the document remains consistent when you add or remove content.

## 1. Use paragraph styles

Choose **Title**, **Subtitle**, **Heading 1**, **Heading 2** and **Normal text** from the styles menu.

A useful hierarchy is:

- Title — the report title.
- Heading 1 — main sections.
- Heading 2 — subsections.
- Heading 3 — smaller topics within a subsection.
- Normal text — paragraphs.

After applying heading styles, use **Insert → Table of contents** to create a table of contents. Update it after editing the report.

## 2. Set up the page

Open **File → Page setup** to choose:

- Paper size, such as A4.
- Page orientation: portrait or landscape.
- Margins for the top, bottom, left and right sides.
- Page colour, where appropriate.

Use section breaks when only part of a report needs different page settings.

## 3. Headers, footers and page numbers

Use **Insert → Headers & footers** to add a report title, author or date. Use **Insert → Page numbers** to number pages. Check the first-page options when a title page should not display a page number.

## 4. Columns and lists

Use **Format → Columns** to create a two-column section. Use **Format → Bullets & numbering** for ordered and unordered lists. Keep list items parallel and concise.

## 5. Tables and images

Use **Insert → Table** to create a table. Open table properties to adjust borders, alignment, cell background and padding. Use **Insert → Image** to add a picture, then select an appropriate text-wrapping option and add a caption.

## 6. Final layout check

- [ ] Heading styles are consistent.
- [ ] The table of contents is updated.
- [ ] Margins and orientation are correct.
- [ ] Headers, footers and page numbers are consistent.
- [ ] Tables and images fit within the page.
- [ ] No heading is stranded at the bottom of a page.
- [ ] The exported PDF has been checked.
