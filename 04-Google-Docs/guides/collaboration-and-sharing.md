# Collaboration and Sharing in Google Docs

Google Docs allows several people to review the same document. Choose permissions carefully and use comments or suggestions to keep feedback understandable.

## Sharing permissions

| Role | What the person can do |
|---|---|
| Viewer | Read the document |
| Commenter | Read and leave comments |
| Editor | Read and make changes |

Use the **Share** button to invite people or manage general access. Give only the permission needed for the task.

## Comments

1. Select the text to discuss.
2. Choose **Insert → Comment** or use the comment shortcut.
3. Write a clear question or suggestion.
4. Mention a collaborator when a response is required.
5. Resolve the comment after the issue has been addressed.

## Suggesting mode

Use the editing-mode menu and select **Suggesting**. Proposed changes appear as suggestions that an editor can accept or reject.

## Version history

Open **File → Version history → See version history** to view earlier versions. Named versions are useful before a major revision or submission.

## Practical activity

Share a copy of your report with a classmate as a Commenter. Ask them to review one section, respond to their comments and inspect the version history.
