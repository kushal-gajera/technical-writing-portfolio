## Technical Report Outline

The [Technical Report Outline](technical-report-outline.md) is a reusable structure for a course report.

It includes:

- Student and course details.
- Abstract and introduction.
- Background and objectives.
- Tools and methodology.
- Implementation and results.
- Challenges and conclusion.
- References and appendix.

## How to Use It

1. Open the outline.
2. Copy it into a new Google Doc.
3. Apply Title, Heading 1 and Heading 2 paragraph styles.
4. Add an automatic table of contents.
5. Replace the prompts with your own report content.
