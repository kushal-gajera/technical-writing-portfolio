# 03 — Formatting Content

This example introduces common text formatting commands in LaTeX.

## Topics

- Bold, italic and typewriter text.
- Font size commands.
- Left, centre and right alignment.
- Text colour using `xcolor`.
- Bulleted and numbered lists.
- Paragraph spacing.

## Compile

```bash
pdflatex main.tex
```

Open the source and change the styles or colours to see how the PDF changes.
