# 05 — Tables and Images

Tables organise values into rows and columns. Images and figures can explain a process or show a result.

## Topics

- Creating a basic table.
- Horizontal and vertical rules.
- Merging columns with `\multicolumn` and rows with `multirow`.
- Dashed rules with the `arydshln` package.
- Long tables that continue across pages.
- Adding, scaling and rotating images with `graphicx`.

## Compile

```bash
pdflatex main.tex
```

The source uses a framed placeholder where an image can be inserted. Replace it with your own file when practising.
