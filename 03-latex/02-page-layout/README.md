# 02 — Page Layout

This example demonstrates how to control page size, margins, orientation, columns, headers and footers.

## Topics

- Paper size and page margins with `geometry`.
- Headers and footers with `fancyhdr`.
- Landscape pages with `pdflscape`.
- Multiple columns with `multicol`.
- Page numbering.

## Compile

```bash
pdflatex main.tex
```

Change the margin value, header text or number of columns and compile again to compare the output.
