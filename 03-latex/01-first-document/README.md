# 01 — First LaTeX Document

This example introduces the basic structure of a LaTeX document.

## Topics

- `\documentclass` and document options.
- The preamble and packages.
- Title, author and date.
- `\begin{document}` and `\end{document}`.
- Table of contents, sections and subsections.
- Bulleted and numbered lists.

## Compile

Run this command from the current folder:

```bash
pdflatex main.tex
```

Open `main.tex` in Overleaf or a desktop editor to change the title, author and section text.
