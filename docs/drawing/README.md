# Drawing software — Inkscape, Xfig and OpenOffice / LibreOffice Draw

Vector diagrams stay sharp when resized and are useful in reports, slides and manuals. This portfolio includes two editable SVG files: [technical writing workflow](../../assets/technical-writing-workflow.svg) and [document lifecycle](../../assets/document-lifecycle.svg).

## Inkscape exercise

1. Open the workflow SVG.
2. Change a label and the fill colour of one box.
3. Align the boxes and distribute them evenly.
4. Add a connector or simple icon.
5. Save the SVG and export a PDF or PNG.

Useful tools: selection, rectangle, ellipse, text, Bezier, fill and stroke, alignment, layers and grouping.

## Xfig exercise

When Xfig is available in your lab, recreate a four-step flowchart using boxes, text and arrows. Export it in a format accepted by your document editor, such as EPS or PDF.

## OpenOffice / LibreOffice Draw exercise

Open the SVG or create a new drawing. Use alignment and distribution tools, group related objects, add a title if needed and export as PDF. Preserve the editable source.

## Diagram quality checklist

- Use a clear reading direction.
- Align shapes and keep consistent spacing.
- Use short labels and readable contrast.
- Do not rely on colour alone to communicate meaning.
- Add a caption and refer to the diagram from the report.
