# Google Docs — practical guide

Google Docs is useful for collaborative reports, comments, suggestions and shared documents.

## 1. Start with a plan

Create a document and name it clearly. Add a title block with report title, student, course, instructor and date. Use **Title**, **Heading 1**, **Heading 2** and **Normal text** styles; avoid manually formatting normal text to look like headings. Insert an automatic table of contents after applying heading styles.

## 2. Page setup and styling

Open **File → Page setup** to select paper size, margins and portrait / landscape orientation. Use section breaks when only part of a report needs a different layout. Insert headers, footers and page numbers from the **Insert** menu. Use **Format → Columns** for a two-column section.

## 3. Format content

Use bold for important terms, italics sparingly, and a restrained accent colour. Use **Format → Align & indent** for alignment and **Format → Bullets & numbering** for lists. Insert equations from **Insert → Equation**.

## 4. Tables and images

Use **Insert → Table** and edit cell background, alignment, border and padding in table properties. Select adjacent cells to merge them. Add images with **Insert → Image**; choose in-line, wrap or break text, resize from a corner handle, and add a caption.

## 5. References and navigation

Use links and bookmarks for cross-references. Use **Tools → Citations** where available, choose one citation style, and insert a bibliography. Keep figure and table numbering consistent.

## 6. Collaboration

Use Share permissions (Viewer, Commenter or Editor), comments and Suggesting mode. Review **File → Version history → See version history** when you need to inspect earlier versions. Never share confidential documents publicly.

## 7. Practical exercise

Create a 4–6 page report from [the template](technical-report-template.md). Include an automatic contents page, three heading levels, one table, one captioned image, one equation, citations and page numbers. Ask a classmate to comment on it.

## Final quality checklist

- [ ] Heading styles and automatic contents are updated.
- [ ] Page size, margins and orientation are correct.
- [ ] Headers, footers and numbering are consistent.
- [ ] Tables and images fit the page and have captions.
- [ ] Citations use one consistent style.
- [ ] Spelling, spacing and alignment have been checked.
