# Start here

Welcome! This page tells you what to open first and what to do next. You do not need to understand every folder at once.

## The easiest way to use this repository

1. Open the [syllabus map](syllabus-map.md) and see which topics are covered.
2. Pick one topic from the list below.
3. Open its guide and read the short explanation.
4. Try the example files and change something yourself.
5. Save evidence of your work and write a note in the [learning journal](learning-journal.md).

## What the diagrams mean

- [Repository map](../assets/repository-map.svg) shows how the folders connect to the course topics.
- [Learning path](../assets/portfolio-flow.svg) shows the order in which the examples fit together.

## Suggested practical order

**First:** Google Docs and LaTeX, because they teach document structure and page formatting.

**Next:** tables, images, references and diagrams, because these make a report easier to understand.

**Then:** Beamer and Doxygen, to present your work and document code.

**Finally:** Gnuplot and Git/GitHub, to visualise data and manage the project history.

## Before you show this to your professor

- Replace example names and dates with your own details.
- Run the tools on your own computer or Overleaf.
- Add screenshots of the results you generated.
- Complete the learning journal using your own words.
- Be ready to explain one example from each major topic.
